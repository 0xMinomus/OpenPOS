# Award

## Juara 1 — Lomba Nasional Web

OpenPOS won **first place** in the **Lomba Nasional Web** (National Web
Competition) organized by **Invention, Universitas Udayana**.

| | |
|---|---|
| **Award** | Juara 1 |
| **Competition** | Lomba Nasional Web |
| **Organizer** | Invention, Universitas Udayana |
| **Project** | OpenPOS |

The award recognizes OpenPOS as a free, offline-capable point-of-sale system
for Indonesian MSMEs, built in the open with a shared web, desktop, and Android
codebase.

Thank you to Invention and Universitas Udayana, and to everyone who uses and
contributes to OpenPOS.
